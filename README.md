# Sardoloop

Sardinian music generator

## Usage

This project is published at [https://sardoloop.it/](https://sardoloop.it/en/original).

## Author

Unfortunately the original author is unknown.

[Daniele Ricci](https://www.trinityteam.it/DanieleRicci) is the author of this project whose purpose is to revive **sardoloop**.

### Development

The repository includes files for comfortable development with **Cursor** or **VSCode**.

Search for `@recommended` extension and install them all.

Last, for Italian spell checking,

- **VSCode** install from the store https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker-italian ;
- **Cursor** run from shell `cursor --install-extension streetsidesoftware.code-spell-checker-italian`.
